# Crypto Autobot

Единый бот для круглосуточной торговли криптовалютными USD-M Futures:

- сам получает закрытые свечи Binance;
- ищет трендовый 4h breakout-сигнал с EMA и ADX-фильтром;
- работает в режимах Paper, Binance Demo и Binance Live;
- рассчитывает размер позиции от допустимого риска;
- в Demo/Live размещает вход, Stop Loss и Take Profit на Binance;
- показывает баланс, позиции, статистику и причины отсутствия сигнала в веб-панели;
- переключает Paper, Demo и Live прямо в веб-панели без смешивания их статистики;
- может отправлять уведомления в Telegram.

## Бесплатный запуск через GitHub

В репозитории уже лежит workflow `.github/workflows/crypto-autobot-demo.yml`. Он:

- запускает один Binance Demo-скан каждые 30 минут;
- хранит состояние между запусками только в зашифрованном виде;
- по умолчанию не отправляет ордера;
- публикует read-only статистику через GitHub Pages без баланса и размера позиций.

Этот вариант предназначен только для Demo. Он подходит стратегии на закрытых 4h
свечах, но не является непрерывным сервером и может запускаться с задержкой.
Пошаговая настройка находится в разделе 7 полной инструкции.

## Безопасный порядок

1. Paper: без ключей и без биржевых ордеров.
2. Binance Demo: виртуальные средства и настоящая механика API.
3. Live: только после проверки статистики и рисков.

Live-конфиг имеет выключенную стратегию, плечо 1x, уменьшенный риск и дополнительную
командную блокировку. API-ключи читаются только из переменных окружения.

## Paper за одну минуту

```bash
cd "/Users/maksympiatachenko/Documents/Трейдинг"
python3 crypto_autobot/bot.py --config crypto_autobot/config.example.json
```

Панель: `http://127.0.0.1:8090`

В панели `Paper` доступен сразу. Для `Demo` нужны Demo API-ключи в переменных
окружения. `Live` дополнительно заблокирован параметром `--allow-live-ui` и фразой
подтверждения. При открытой позиции смена режима запрещена.

Один проход без постоянного запуска:

```bash
python3 crypto_autobot/bot.py \
  --config crypto_autobot/config.example.json \
  --once
```

## Быстрый Demo-профиль

Для проверки рыночных ордеров есть отдельный внутридневной профиль на закрытых
15-минутных свечах:

```bash
caffeinate -i python3 crypto_autobot/bot.py \
  --config crypto_autobot/config.demo.scalp.example.json \
  --enable-orders
```

В панели появится блок `Проверка рыночного ордера`. Он позволяет открыть одну
маленькую Long или Short позицию на Binance Demo и сразу поставить Stop Loss и
Take Profit. Проверка заблокирована в Paper и Live. Сначала добавь виртуальные
USDT в кошелек Binance Futures Demo.

Это профиль для проверки исполнения и сбора Demo-статистики, а не готовая
прибыльная стратегия. На 30-дневном тесте с комиссией и проскальзыванием его
результат был слегка отрицательным.

## Полная инструкция

Открой [ИНСТРУКЦИЯ_RU.md](ИНСТРУКЦИЯ_RU.md). Там есть:

- создание Binance Demo API;
- проверка подключения без ордеров;
- запуск Demo и Live;
- бесплатный запуск Binance Demo через GitHub Actions и Pages;
- исторический backtest с комиссиями и проскальзыванием;
- автоматический перезапуск через systemd;
- правила безопасности и частые ошибки.

## Проверка кода

```bash
python3 -m unittest discover -s crypto_autobot/tests -v
```

Бот не гарантирует прибыль. До Live оцени статистику на достаточном числе Demo-сделок,
максимальную просадку, комиссии и поведение во время нестабильного рынка.
